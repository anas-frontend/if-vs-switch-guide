المقارنة بين if و Switch Case

تستخدم if لاختبار الشروط المختلفة، بينما تستخدم switch عندما يكون لدينا متغير واحد له عدة قيم ثابتة.

مثال باستخدام if

let degree = 85;

if(degree >= 90){
    console.log("A");
}
else if(degree >= 80){
    console.log("B");
}
else{
    console.log("Fail");
}

مثال باستخدام Switch

let day = 2;

switch(day){

case 1:
console.log("Saturday");
break;

case 2:
console.log("Sunday");
break;

default:
console.log("Unknown");

}

جدول المقارنة

if switch
تدعم جميع الشروط تدعم القيم الثابتة
تستخدم > و < و >= لا تدعم المقارنات
تدعم && و || لا تدعمها مباشرة
أفضل للشروط المعقدة أفضل للحالات الكثيرة
