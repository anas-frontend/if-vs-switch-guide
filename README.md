# if vs switch (Arabic)

A small study page in Arabic that compares `if` and `switch` in JavaScript. It has a short explanation, one code example for each, a comparison table and a note about when to use each one.

The page is right to left (`dir="rtl"`), but the code blocks stay left to right.

## Built with

HTML and CSS only.

## How to run

Open `index.html` in your browser.
